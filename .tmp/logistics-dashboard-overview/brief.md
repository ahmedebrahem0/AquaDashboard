# Logistics Dashboard Overview Brief

Implement Phase 4 Data Contracts and Phase 5 Dashboard Overview for the Arabic RTL logistics dashboard, closely matching public/Dashboard.png. Audience: company reviewers assessing architecture, fidelity, accessibility, responsiveness, maintainability, and performance.

Use strongly typed deterministic datasets for today, week, and month; pure validating selectors; async Next.js 16 search params; server-rendered cards; URL-backed client filter controls; and an isolated print action. Build a compact responsive four-card KPI grid with accessible trend text and inline SVG sparklines. Preserve the shell and stop before orders, map, and analytics. Use an off-white canvas, white bordered cards, fine shadows, deep indigo controls, and green/red semantic accents. No new raster assets or dependencies.

Verify lint, typecheck, supported and invalid URL ranges, responsive widths, drawer regression, screenshots, and production build. Report the known Cairo font network issue honestly if it persists.
